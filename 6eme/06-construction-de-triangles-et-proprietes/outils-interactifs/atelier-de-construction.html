Atelier de construction

Mode d'emploi
  • Point : clique pour placer un point. Choisis d'abord son nom dans la liste. Le point s'accroche aux croisements (repère orange).
  • Règle : clique sur le point de départ, puis clique pour finir le segment. La longueur s'affiche pendant le tracé (au millimètre).
  • Demi-droite : clique sur l'origine, puis sur un point par lequel elle passe.
  • Compas : 1) clique sur le centre, 2) clique pour choisir l'écartement (le rayon s'affiche), 3) tourne et clique pour finir l'arc.
  • Rapporteur : 1) clique sur le sommet de l'angle, 2) clique sur un point de l'autre côté (le zéro), 3) tourne et clique pour placer le repère à la bonne mesure.
  • Gomme : clique sur un tracé pour l'effacer. Annuler retire le dernier tracé.
  • Quand le triangle est terminé (trois points nommés et trois côtés tracés), clique sur Vérifier.
